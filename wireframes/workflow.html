기획전 제작 체계 구축

담당 범위 · 디자인·코드 템플릿 제작 / 요청 데이터 시트 제작 / 업무 자동화

발매·프로모션 기획전을 유형별로 템플릿화하고, 요청 정보를 전달하는 데이터 시트를 제작했습니다. 운영 시트의 공통 입력 항목과 유형별 추가 항목을 기준으로 제작 구조를 정리했습니다. Slack 자동화의 세부 연동 방식은 추가 확인이 필요합니다.

01 / 유형 선택 기준

기획 목적과 에셋에 맞춰
템플릿을 선택합니다.

발매는 기본 / 프로모션 / 프로모션+증정 / 발매+드로우로 구분하고, 프로모션 기획전은 별도 혜택 영역의 유무로 구분합니다. 아래 유형을 누르면 선택 조건과 페이지 구조를 확인할 수 있습니다. 이 와이어프레임에서는 제품 카드 4개를 한 줄로 표시합니다.
